Responsive building blocks

Fluid layout

Grid changes from three columns on desktop to a single column on mobile using grid-template-columns and media queries.

Scalable type

Font sizes use clamp() and breakpoint‑specific values to stay readable on phones, tablets, and large screens.

Flexible media

Images and cards never overflow — max-width: 100% and padding adjustments keep everything usable.

Gallery that reflows

On desktop you see three images per row; on tablet two; on mobile one.

Why responsive matters

Mobile traffic now exceeds desktop. A responsive layout ensures that text stays legible, buttons remain tappable, and images scale gracefully — without horizontal scrolling or zooming.

This page uses an external styles.css with three main breakpoints:

  • ≤ 480px — phones (single column, smaller padding)
  • 481–768px — large phones / small tablets (2‑column grids)
  • ≥ 1024px — desktops (3‑column layouts, larger type)
