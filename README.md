## 📌 About Cognifyz Technologies Internship

The **Cognifyz Technologies Internship** is a practical learning experience focused on strengthening frontend development skills through structured, task-based implementation.

This repository contains my internship work, beginning with foundational HTML and CSS concepts and progressing toward responsive layouts, JavaScript interactivity, API integration, form validation, Tailwind CSS, and Sass preprocessing.

The primary objective of this repository is to demonstrate continuous learning, practical problem-solving, clean project organization, and the ability to transform development requirements into functional web experiences.

> **Internship Focus:** Frontend Development • UI Styling • Responsive Design • JavaScript • API Integration • CSS Architecture

---

## 🎯 Internship Objectives

- Build a strong foundation in semantic HTML5.
- Understand inline and external CSS styling techniques.
- Develop responsive layouts for mobile, tablet, and desktop devices.
- Implement JavaScript-based DOM manipulation and user interaction.
- Work with external APIs using the Fetch API.
- Create and validate user-friendly forms.
- Explore utility-first styling with Tailwind CSS.
- Understand modular and maintainable styling with Sass/SCSS.
- Improve code organization, documentation, and version-control practices.
- Build a portfolio of progressively challenging frontend tasks.

## ⚙️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/MdAnasAslam/Cognifyz_Internship.git
```

### 2. Move into the Project Directory

```bash
cd Cognifyz_Internship
```

### 3. Open the Project

Open the repository in **Visual Studio Code**.

```bash
code .
```

You can also open any task's `index.html` file directly in a browser.

### 4. Use Live Server

For a better development experience:

1. Install the **Live Server** extension in VS Code.
2. Open the required task folder.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

---

## 🎨 Running the Sass Project

Navigate to the Sass task:

```bash
cd ExpertLevel/02_Task
```

Install the dependencies:

```bash
npm install
```

Run Sass in watch mode:

```bash
npm run sass
```

Create a compressed production CSS file:

```bash
npm run sass:build
```

The SCSS source files are compiled into browser-readable CSS.

### Sass Workflow

```text
SCSS Source Files
        │
        ▼
Sass Preprocessor
        │
        ▼
Compiled CSS
        │
        ▼
HTML + CSS
        │
        ▼
Web Browser
```
