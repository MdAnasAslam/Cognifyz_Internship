# 🌐 Interactive Web — Task 1

A clean, responsive, and beginner-friendly HTML webpage developed as part of **Task 1: Basic HTML Page**. This project demonstrates fundamental HTML5 structure, CSS styling, responsive design, and image integration.

## 📌 Project Overview

This project focuses on creating a basic yet visually appealing webpage using **HTML5 and CSS3**. It includes a structured layout with headings, paragraphs, an image, and a task completion note.

The webpage is designed to render correctly across modern browsers and provides a foundation for future enhancements such as JavaScript interactivity, API integration, and advanced frontend development.

## ✨ Features

* **Semantic HTML5 Structure** — Uses HTML, Head, and Body elements.
* **Responsive Design** — Adapts to different screen sizes using CSS media queries.
* **Modern UI Design** — Clean layout with rounded corners, shadows, and consistent spacing.
* **Google Sans Typography** — Uses Google Sans for a professional visual appearance.
* **Image Integration** — Displays an image using the Unsplash CDN.
* **Mobile-Friendly Layout** — Includes responsive typography and padding adjustments.
* **Structured Content** — Organized headings, paragraphs, and task information.
* **CSS Styling** — Uses custom CSS for colors, layout, hover effects, and responsiveness.
