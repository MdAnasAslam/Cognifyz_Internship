# 🎨 Interactive Web — Task 2

## Inline CSS Styling Demo

A responsive and visually structured webpage developed as part of **Task 2: Inline CSS Styling**. This project demonstrates how inline CSS can be applied directly to HTML elements using the `style` attribute to customize colors, typography, spacing, borders, backgrounds, and visual effects.

## 📌 Project Overview

The objective of this task is to understand and implement **Inline CSS styling** within an HTML document. Different HTML elements, including headings, paragraphs, containers, and text spans, are styled individually using inline CSS properties.

The webpage showcases various design combinations while maintaining a clean, modern, and readable user interface.

This project strengthens the understanding of HTML styling fundamentals and provides a foundation for learning internal and external CSS in future frontend development tasks.

## ✨ Features

* **Inline CSS Implementation** — Applies styling directly through the HTML `style` attribute.
* **Typography Customization** — Demonstrates different font sizes, weights, and letter spacing.
* **Color Styling** — Uses multiple text and background color combinations.
* **Box Styling** — Includes padding, border radius, borders, and box shadows.
* **Responsive Layout** — Uses a flexible page wrapper and viewport configuration.
* **Visual Design** — Uses rounded containers and color-coded content sections.
* **Google Sans Font** — Integrates Google Fonts for modern typography.
* **CSS Property Demonstration** — Shows practical usage of multiple CSS properties in one webpage.

### Inline CSS Example

```html
<h1 style="color: blue; font-size: 2rem;">
  Hello, World!
</h1>
```

The `style` attribute applies CSS directly to the `h1` element.

## ⚖️ Inline CSS vs External CSS

Inline CSS is useful for quick styling and specific element-level customization. However, external CSS is generally more suitable for larger projects because it improves maintainability, reusability, and separation of concerns.
